A beginner-friendly Machine Learning project that explores five classification algorithms to predict passenger survival using the Titanic dataset.

## 📌 About the Project

This project is part of my hands-on Machine Learning learning journey. Using Python, Scikit-learn, and Google Colab, I implemented five different classification models to explore how machine learning can predict whether a passenger survived the Titanic disaster.

## 📂 Dataset

- **Dataset:** Titanic Passenger Dataset
- **Format:** CSV
- **Problem Type:** Binary Classification
- **Target Variable:** `Survived`

The dataset was provided as part of the tutorial followed for this project.

## 🤖 Machine Learning Models

The following classification algorithms were implemented:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Gaussian Naive Bayes
4. Decision Tree Classifier
5. Support Vector Machine (SVM)
